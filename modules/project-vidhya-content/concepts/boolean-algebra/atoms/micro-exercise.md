Simplify the Boolean expression $F = A'B + AB$ using the algebraic laws directly, not a K-map.

<details>
<summary>Answer</summary>

$F = B(A'+A) = B\cdot1 = B$ — factoring out $B$, then using the complement law $A'+A=1$.
</details>
