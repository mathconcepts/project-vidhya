## Root cause (one paragraph)

The demo read as a question bank because (RC1) a concept-ID mismatch (`calculus-derivatives`/`linear-algebra-eigenvalues` vs graph ids `derivatives-basic`/`eigenvalues`) made the rich atom path — animations, interactives, strategy — unreachable for 81/82 concepts, with the error swallowed silently; (RC2) all 82 shipped explainers were `model:"placeholder"` artifacts generated without an API key; (RC3) the legacy composer manufactured "lessons" from MCQs, splitting answer explanations on periods into fake steps. The teaching machinery already existed; it was unplugged.

## Named errors (zero-silent-failures map)

| Error | Trigger | Caught | User/admin sees |
|---|---|---|---|
| ConceptNotFoundError | concept without atoms dir | lesson-routes | legacy lesson + loud log + counter |
| QuotaExhaustedError | provider quota mid-run | job-runner | job status `paused`, resumable checkpoint |
| ProviderTimeoutError | provider timeout | job-runner | retry ×2 → skip recorded in checkpoint |
| CheckpointCorruptError | unparseable checkpoint | job-runner | job refuses start, fail closed |
| ExtractionEmptyError | scanned/image PDF | uploads | protected refusal copy, upload kept |
| (409) JobAlreadyRunning | concurrent start | job-routes | 409 + current status |
| (503) Jobs disabled | CONTENT_JOBS_DISABLED | job-routes | 503 + kill-switch message |
