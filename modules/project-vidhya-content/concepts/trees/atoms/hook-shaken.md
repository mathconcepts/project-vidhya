Link 4 towns with roads, paying per kilometre. 3 roads connect all 4 towns with no loop — that's a tree. Add a 4th road and you create exactly one cycle: a loop carrying traffic nowhere new, since every town was already reachable. $n$ towns need exactly $n-1$ roads, never more, never fewer.
