The calculation above assumed the salt supplies the SAME acid's own conjugate base — worth checking, since it is easy to build a lookalike mixture that is not actually a buffer at all.

Take a near-identical setup: $0.2$ mol $\text{CH}_3\text{COOH}$ mixed with $0.1$ mol $\text{NaCl}$ in $500\ \text{mL}$. This looks like the same kind of problem — a weak acid plus a salt in solution — but $\text{Cl}^-$ is not $\text{CH}_3\text{COOH}$'s conjugate base. There is no $[\text{A}^-]$ term to put into Henderson–Hasselbalch at all; this mixture is not a buffer, and its pH has to be found from $\text{CH}_3\text{COOH}$'s own ionisation alone, ignoring $\text{NaCl}$ entirely.

**A weak acid plus a salt is necessary for a buffer — nowhere near sufficient.** The salt must supply that SAME acid's own conjugate base ion, not merely any negatively charged species. Name the acid, name its conjugate base, and confirm the salt actually supplies that specific ion, before reaching for Henderson–Hasselbalch on any mixture.
