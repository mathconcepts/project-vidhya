**Problem:** A concave mirror has a focal length of magnitude $15\text{ cm}$. An object is placed $30\text{ cm}$ in front of it. Find the image distance and magnification, and state the image's nature.

---

**Step 1 — Recognise the special position before touching the formula.** $u=-30\text{ cm}=2f$ (since $f=-15\text{ cm}$): the object sits exactly at the centre of curvature. For a concave mirror, this position always sends the image straight back to the same point.

$$\boxed{v=-30\text{ cm}, \quad m=-1 \text{ (real, inverted, same size)}}$$

**Why the shortcut is not "the image is always at $C$".** This recognition only shortcuts *this one special position* — it is not a general substitute for the mirror formula. Nudge the object to $u=-25\text{ cm}$ instead (no longer exactly $2f$), and the shortcut gives nothing at all; the formula must be solved properly, giving $v=-37.5\text{ cm}$ and $m=-1.5$ — no longer at $C$ and no longer the same size as the object.
