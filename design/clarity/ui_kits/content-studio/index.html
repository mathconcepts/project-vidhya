Draft · eigenvalues-intro

✓ Verified · Wolfram
An eigenvalue of a square matrix A is a scalar λ for which there exists a non-zero vector v with Av = λv. Geometrically, v is a direction that A only stretches — it never turns it.

To find them, solve det(A − λI) = 0. The left-hand side is a polynomial in λ of the same degree as the matrix, so a 3×3 matrix has three eigenvalues counted with multiplicity.
