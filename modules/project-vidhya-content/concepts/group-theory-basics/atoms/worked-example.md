# Group Theory — Worked Examples

## Problem 1: Prove $(\mathbb{Z}_6, +_6)$ is Cyclic and Find All Subgroups (GATE Style)

**Part A — Prove it is cyclic.**

Claim: $\mathbb{Z}_6 = \langle 1 \rangle$.

Starting from 0, repeatedly add 1 (mod 6):
$$0 \xrightarrow{+1} 1 \xrightarrow{+1} 2 \xrightarrow{+1} 3 \xrightarrow{+1} 4 \xrightarrow{+1} 5 \xrightarrow{+1} 0$$

All 6 elements are generated. Hence $(\mathbb{Z}_6, +_6)$ is cyclic with generator 1. $\checkmark$

**Part B — Find all subgroups.**

By Lagrange's theorem, subgroup orders must divide $|\mathbb{Z}_6| = 6$.

Divisors of 6: $1, 2, 3, 6$.

| Order | Subgroup | Generated by |
|---|---|---|
| 1 | $\{0\}$ | 0 (trivial) |
| 2 | $\{0, 3\}$ | 3 (since $3+3=6\equiv 0$) |
| 3 | $\{0, 2, 4\}$ | 2 (since $2+2+2=6\equiv 0$) |
| 6 | $\{0,1,2,3,4,5\}$ | 1 (the whole group) |

There are exactly 4 subgroups, one for each divisor of 6 — consistent with the theorem that $\mathbb{Z}_n$ has exactly one subgroup of order $d$ for each divisor $d$.

## Problem 2: Invertible Matrices Form a Group (GATE Style)

**Question:** Show that $GL_2(\mathbb{R})$, the set of all $2 \times 2$ invertible real matrices, is a group under matrix multiplication.

**Closure:** If $A, B \in GL_2(\mathbb{R})$, then $\det(AB) = \det(A)\det(B) \neq 0$ (product of two non-zero numbers). So $AB$ is invertible $\Rightarrow AB \in GL_2(\mathbb{R})$. $\checkmark$

**Associativity:** Matrix multiplication is always associative. $\checkmark$

**Identity:** The $2 \times 2$ identity matrix $I = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$ satisfies $AI = IA = A$ and $\det(I) = 1 \neq 0$. $\checkmark$

**Inverse:** Since every matrix in $GL_2(\mathbb{R})$ has $\det(A) \neq 0$, the matrix inverse $A^{-1}$ exists. Moreover $\det(A^{-1}) = 1/\det(A) \neq 0$, so $A^{-1} \in GL_2(\mathbb{R})$. $\checkmark$

**Note:** $GL_2(\mathbb{R})$ is **not abelian** (matrix multiplication is not commutative in general).

## Problem 3: Order of Elements (GATE Style)

**Question:** In $(\mathbb{Z}_{12}, +_{12})$, find the order of the element 4.

**Solution:**

Find the smallest $k > 0$ such that $4k \equiv 0 \pmod{12}$.

$$4 \times 1 = 4,\quad 4 \times 2 = 8,\quad 4 \times 3 = 12 \equiv 0$$

So $\text{ord}(4) = 3$.

**Formula verification:** $\text{ord}(a)$ in $\mathbb{Z}_n$ equals $n/\gcd(n,a)$.

$$\text{ord}(4) = \frac{12}{\gcd(12, 4)} = \frac{12}{4} = 3 \checkmark$$

## Problem 4: Applying Lagrange's Theorem (GATE Style)

**Question:** A group $G$ has order 15. Can $G$ have a subgroup of order 6?

**Solution:**

By Lagrange's theorem, the order of any subgroup must **divide** $|G| = 15$.

$$15 = 3 \times 5 \implies \text{divisors of } 15 = \{1, 3, 5, 15\}$$

Since $6$ does not divide $15$, **no subgroup of order 6 can exist** in $G$.

**Also:** Every element's order must divide 15, so possible element orders are 1, 3, 5, 15.
