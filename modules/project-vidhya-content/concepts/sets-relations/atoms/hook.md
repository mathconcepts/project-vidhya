Group six numbers, $1$ through $6$, into as few piles as possible so every two numbers sharing a pile leave the same remainder on division by $3$. Sort them and count the piles.

The sorting itself is a **relation**: "leaves the same remainder as." It happens to be reflexive (every number matches itself), symmetric (if $a$ matches $b$, $b$ matches $a$), and transitive (matching a common third number forces $a$ and $b$ to match each other) — three properties that, together, guarantee the sorting works cleanly, with no number caught between two piles.
