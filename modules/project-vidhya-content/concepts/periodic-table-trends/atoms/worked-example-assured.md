**Problem:** Arrange nitrogen, oxygen and fluorine by increasing first ionisation enthalpy, and state exactly which single step in that order is the exception.

---

**Step 1 — Real values (kJ/mol).** N = 1402, O = 1314, F = 1681. So the order is $O < N < F$.

---

**Step 2 — The distinction that actually costs marks.** Only the $N \to O$ step is the exception; $O \to F$ is completely ordinary. N ($2p^3$, half-filled, no pairing) to O ($2p^4$, one pair forms) drops because of new electron-pair repulsion. O to F ($2p^5$) has no new instability to cross — it is just one more electron added to an already-paired subshell, so enthalpy rises exactly as the plain across-period rule predicts.

---

**Step 3 — The trap this guards against.** A common wrong instinct is to expect a second dip somewhere between O and Ne, reasoning "there are always two dips per period, so there should be another one here." There is not: per period there are exactly two anomaly points, tied to specific configuration changes ($2s^2 \to 2s^22p^1$ and $2p^3 \to 2p^4$), and neither recurs a second time within the same period. $\boxed{IE(O) < IE(N) < IE(F)}$, with the single exception sitting only at $N \to O$.
