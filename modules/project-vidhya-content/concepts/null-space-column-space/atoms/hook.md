Every matrix has a set of directions it completely erases, and a set of directions that catch everything it outputs. Feed this one every arrow in the plane: almost all of them end up on the very same slanted line — that line is the column space. One direction, though, gets pushed all the way down to the center point and disappears: that direction is the null space.
