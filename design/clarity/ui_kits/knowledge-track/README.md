# UI kit — knowledge-track shell

The non-exam student shell, from `frontend/src/pages/app/KnowledgeHomePage.tsx`.
Touchpoints in `guidelines/journey-knowledge-studio-ceo.md`.

- **No urgency anywhere** — no countdown, no days-left, no red. Position in the curriculum is the headline: "23 of 40 concepts".
- **Next concept** is the focal block, and the reason is a sentence about prerequisites, not a score.
- **Concept map** uses four states: mastered (green), next (indigo), open (white), locked (grey). A locked row explains itself — "Opens once you've done derivatives" — instead of showing a padlock.
- **K→E bridge** appears once at 70% coverage and is phrased as an offer with a real "Not now". It never asks again (`vidhya.ke_bridge_shown`).
