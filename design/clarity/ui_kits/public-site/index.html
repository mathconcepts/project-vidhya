Why row reduction never changes your answers

Under exam pressure, the doubt always arrives at the same moment: you have eliminated three rows, the matrix looks nothing like the one you started with, and some part of you wonders whether the answer survived the surgery.

It did, and the reason takes one line.

✓ Verified · Wolfram
det(EA) = det(E)·det(A), and det(E) ≠ 0 for every elementary matrix E — so every row operation is invertible.

Run the operations backwards and you recover the original system exactly. A solution cannot be created by a reversible step, and it cannot be destroyed by one either. The set you end with is the set you started with, written more usefully.
