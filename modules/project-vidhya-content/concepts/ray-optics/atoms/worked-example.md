**Problem:** A concave mirror has a focal length of magnitude $15\text{ cm}$. An object is placed $30\text{ cm}$ in front of it. Find the image distance and magnification, and state the image's nature.

---

**Step 1 — Assign signs.** The mirror is concave, so $f=-15\text{ cm}$. The object is in front of the mirror, so $u=-30\text{ cm}$.

---

**Step 2 — Notice $u$ is exactly $2f$.** $2f = -30\text{ cm} = u$ — the object sits exactly at the mirror's **centre of curvature**, a special position worth recognising directly.

---

**Step 3 — Apply the mirror formula.** $\dfrac{1}{v}+\dfrac{1}{u}=\dfrac{1}{f} \Rightarrow \dfrac{1}{v} = \dfrac{1}{-15}-\dfrac{1}{-30} = -\dfrac{1}{15}+\dfrac{1}{30} = -\dfrac{1}{30}$, so $v=-30\text{ cm}$.

---

**Step 4 — Magnification.** $m = -\dfrac{v}{u} = -\dfrac{-30}{-30} = -1$.

$$\boxed{v=-30\text{ cm}, \quad m=-1}$$

---

**Step 5 — Read off the image's nature.** $v$ negative, in front of the mirror: **real**. $m=-1$: same size as the object, **inverted**. This matches the standard geometric fact for a concave mirror — an object placed exactly at the centre of curvature forms its image at the same point, real, inverted, and the same size.
