An equivalence relation's three axioms aren't independently interesting — together they guarantee the relation partitions the set into disjoint classes, the Fundamental Theorem of Equivalence Relations. Drop any one axiom and the guarantee breaks: reflexive + transitive alone (a **preorder**) permits $a\sim b$ without $b\sim a$, so "classes" can overlap or fail to cover an element cleanly.

The exam-relevant check is never "does this look like grouping" — it's confirming all three axioms hold, especially symmetry, the one preorders quietly drop.
