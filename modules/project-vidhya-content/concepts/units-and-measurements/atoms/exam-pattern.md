**How JEE actually asks this.**

- **MCQ: dimensional formula matching.** Given a formula with an unfamiliar-looking constant (a spring constant, a viscosity coefficient), find its dimensional formula by matching both sides of the equation using the principle of homogeneity (only quantities with identical dimensions can be added or set equal) — never by trying to recall the constant's "usual" unit from memory.

- **NAT: significant figures in a stated calculation.** Given two or more measured numbers with stated precision, compute a sum, product, or power and report the answer to the correct number of significant figures or decimal places. The most common way this is set as a trap: burying an addition inside what looks like a multiplication problem, or the reverse.

- **NAT/MCQ: percentage error in a derived quantity.** Given the errors in each measured input and a formula combining them (a product, quotient, or power — sometimes several at once, like $Z = A^2B^3/C$), compute the percentage error in $Z$ by adding the *relative* errors, each multiplied by its own power.

- **Trap: least count decides the number of decimal places you are allowed to claim.** An instrument's least count sets a hard floor — no amount of careful arithmetic afterward can report a length to more decimal places than the instrument itself could measure.

- **Time budget:** a significant-figures or error-propagation NAT should take under $45$ seconds once the correct combining rule (addition vs. multiplication vs. power) is identified — the arithmetic itself is short; identifying which rule applies is the actual test.
