A suspension bridge's main cable sags in a curve close to a parabola. An inspector's safety rule says the walkway underneath must stay *below* the cable everywhere in a stretch — so the inspector needs to know exactly where the cable's height minus the walkway's height, a quadratic expression in position $x$, is positive.

Solving that quadratic equation gives the two positions where cable height exactly equals walkway height — the boundary points. Between them, if the parabola opens the right way, the cable sits above the walkway (safe); outside them, the gap could close or reverse. This is exactly a **quadratic inequality**: not "where is this expression zero" but "where is it positive, and where is it negative" — and the roots of the equation are the only two places the sign can possibly flip.
