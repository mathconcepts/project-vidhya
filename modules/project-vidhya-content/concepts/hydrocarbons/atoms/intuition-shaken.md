Count electrons for one ring at a time.

**Benzene**, $\text{C}_6\text{H}_6$: $6$ carbons in the ring, each carrying one p-orbital, each giving one electron to the shared pi system. Total: $6$ pi electrons.

Check against $4n+2$: does $4n+2=6$ have a whole-number solution? $4n=4$, so $n=1$. Yes — a whole number. Benzene is aromatic.

Now **cyclobutadiene**, $\text{C}_4\text{H}_4$: $4$ carbons, $4$ pi electrons. Check: $4n+2=4$ gives $4n=2$, $n=0.5$ — not a whole number. Cyclobutadiene fails Huckel's rule. Since its electron count is exactly $4n$ ($n=1$), it is not merely non-aromatic, it is **antiaromatic** — actively less stable than a plain open chain with the same bonds.

Same ring shape, same alternating bonds drawn on paper, opposite outcome — because the electron count, not the picture, decides it.
