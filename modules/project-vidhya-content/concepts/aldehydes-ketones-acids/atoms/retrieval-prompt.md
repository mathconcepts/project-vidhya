**Question:** State the one check that decides whether a carbonyl compound undergoes aldol condensation or the Cannizzaro reaction with a strong base. Then state which reagent distinguishes an aldehyde from a ketone by a colour change.

<details>
<summary>Answer</summary>

**The check:** does the carbon next to the carbonyl carbon (the alpha carbon) have a hydrogen on it?

- Yes (an alpha-hydrogen is present): the base removes it to form an enolate, which attacks a second carbonyl molecule — **aldol condensation**.
- No: the enolate route is closed, so the base attacks the carbonyl carbon directly, and the molecule disproportionates — **Cannizzaro reaction**.

**The reagent:** Tollens' reagent, $\text{Ag(NH}_3)_2^+$. An aldehyde reduces it to metallic silver, coating the test tube in a mirror; a ketone does not react.

</details>
