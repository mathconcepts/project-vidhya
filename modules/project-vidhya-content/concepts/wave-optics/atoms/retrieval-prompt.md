**Question:** State the condition on path difference for a bright fringe and for a dark fringe in Young's double-slit experiment, and state the fringe-width formula.

<details>
<summary>Answer</summary>

**Bright (constructive):** $\Delta = n\lambda$, $n=0,\pm1,\pm2,\ldots$

**Dark (destructive):** $\Delta = (n+\tfrac12)\lambda$, $n=0,\pm1,\pm2,\ldots$

**Fringe width:** $\beta = \dfrac{\lambda D}{d}$.

</details>
