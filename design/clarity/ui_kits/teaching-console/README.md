# UI kit — teaching console

Teacher surface at `/teaching`. Built from `docs/TEACHER-JOURNEY.md`; see
`guidelines/journey-teacher-admin.md`.

- **Teach next** is the single focal block: one concept, the number that justifies it, one button.
- **Teaching brief** opens as a right drawer with the cohort's own misconceptions, a starting point based on representation preference, and what to run live. Both actions — push to review, announce — are on the brief, where the decision is made.
- **Worth a message** replaces a passive roster: each flagged student carries a "copy a check-in" that fills a message for the teacher's own WhatsApp. No in-app DMs, by design.
- Privacy is stated on the page: mastery and flags, never answers or emotional detail, and students see the same list.
