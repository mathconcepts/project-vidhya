"The string pulls $m_1$ and $m_2$ with the same force, since it's the same string" is true of the *tension* but easy to over-extend into "so both blocks accelerate for the same reason" — they do not. $m_1$ accelerates because tension is the *only* horizontal force on it; $m_2$ accelerates because gravity and tension act as two *opposing* forces whose difference drives the motion.

Counterexample: if $m_1$'s table were not frictionless, tension would still be the same string tension, but $m_1$'s equation would gain a friction term, $T-f=m_1a$, while $m_2$'s equation stays exactly as before, $m_2g-T=m_2a$ — same tension, genuinely different equations, because each free-body diagram answers only for the forces acting on *its own* block.
