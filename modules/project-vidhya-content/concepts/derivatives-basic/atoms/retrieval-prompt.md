From memory, before checking: what is the power rule for $\frac{d}{dx}x^n$, and which extra factor does the chain rule add when the base is a function — e.g. in $\frac{d}{dx}(\sin x)^3$?

<details>
<summary>Answer</summary>

$\frac{d}{dx}x^n = nx^{n-1}$. When the base is a function $g(x)$, the chain rule multiplies by $g'(x)$: $\frac{d}{dx}(\sin x)^3 = 3(\sin x)^2 \cdot \cos x$.
</details>
