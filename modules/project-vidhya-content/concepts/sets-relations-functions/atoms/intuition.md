A **set** is any well-defined collection — "the digits 0 to 9", "students in a class". "Well-defined" means anyone can check, without argument, whether something belongs. "Tall students" is not a set (tall by whose ruling?); "students taller than 170 cm" is.

Draw a set A on the left, a set B on the right, and arrows from A to B. Any bunch of arrows at all is a **relation** — some elements might send out two arrows, some none. A **function** is the strict special case: *every* element of A sends out *exactly one* arrow.

The **domain** is where arrows start (all of A used); the **range** is where arrows actually land — only the used part of B. The **codomain** is the whole of B, arrows or not. Range and codomain match in easy examples and quietly split apart in harder ones — that gap is where "onto" questions live.

**One-one** means no two arrows crash into the same point of B. **Onto** means every point of B has at least one arrow landing on it — range equals codomain.
