**Problem:** For $A(g) \rightleftharpoons B(g)$, $K_c = 4.0$ at a given temperature. At a certain instant, $[A]=2.0$ M and $[B]=3.0$ M. In which direction, if any, does the reaction proceed?

---

**Step 1 — Count what is being compared: the current state ($Q$) against the fixed equilibrium value ($K_c$), using the identical expression.** $Q = \dfrac{[B]}{[A]}$, the same form as $K_c = \dfrac{[B]}{[A]}$ at equilibrium.

---

**Step 2 — Compute $Q$ from the given, non-equilibrium concentrations.** $Q = \dfrac{3.0}{2.0} = 1.5$.

---

**Step 3 — Compare $Q$ to $K_c$.** $Q(1.5) < K_c(4.0)$.

$$\boxed{Q < K_c \Rightarrow \text{reaction shifts forward (toward } B\text{)}}$$

---

**Step 4 — State the physical meaning.** Since $Q$ is smaller than the value the system settles to, there is not yet enough $B$ relative to $A$ — the forward reaction runs, converting more $A$ into $B$, until $Q$ rises to meet $4.0$ exactly.

---

**Why this is not a Le Chatelier question.** No external stress (added reactant, temperature change) was applied here — this is simply a system caught mid-approach to its own equilibrium, and $Q$ vs. $K_c$ answers "which way does it still need to move", independently of Le Chatelier's Principle, which is about a system *already at* equilibrium being disturbed.
