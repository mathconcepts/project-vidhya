"Fast enough that no heat escapes" sounds like it should mean "temperature stays the same." It means close to the opposite. Zero heat exchange (an **adiabatic** process, $Q=0$) is exactly the condition under which temperature changes the *most* for a given compression, since every joule of work then has nowhere to go except straight into internal energy.

An **isothermal** process ($T$ held constant, which needs slow, continuous heat exchange with the surroundings) is a different scenario entirely, and can behave almost oppositely under compression. Treating "adiabatic" and "isothermal" as two names for the same idea — both loosely meaning "nothing complicated is happening" — silently swaps which one predicts a sharp temperature rise in a fast pump stroke and which one predicts almost none.
