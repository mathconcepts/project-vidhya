**Cross-concept check: atomic-structure → chemical-bonding.**

**Question 1 (electron configuration decides bonding behaviour):** Nitrogen (atomic number 7) has configuration $1s^2\,2s^2\,2p^3$. Using Hund's rule, how many unpaired electrons does it have in its $2p$ subshell, and what does that predict about how many bonds it typically forms?

*Answer:* $2p^3$ places 3 electrons into 3 separate $2p$ orbitals, one each, all unpaired (Hund's rule — no pairing needed since there are exactly enough orbitals). All 3 unpaired electrons are available to form 3 covalent bonds, which is exactly why nitrogen forms 3 bonds in $\text{NH}_3$.

**Question 2 (a filled subshell bonds differently from a partially filled one):** Neon has configuration $1s^2\,2s^2\,2p^6$ — every orbital in $n=2$ is completely filled, no unpaired electrons anywhere. What does this predict about neon's tendency to form covalent bonds?

*Answer:* With zero unpaired electrons, neon has no readily available electrons to share in a covalent bond — this is exactly why neon is chemically inert and does not form ordinary molecules, unlike nitrogen.

**Why this drill exists:** chemical bonding is not a separate topic that starts from scratch — the number of unpaired electrons an atom's configuration produces (straight from atomic structure) directly sets how many bonds that atom can form.
