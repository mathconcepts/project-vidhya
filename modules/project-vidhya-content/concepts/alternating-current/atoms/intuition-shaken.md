Draw one arrow pointing straight up — call it the voltage phasor, at angle $90^\circ$ on a clock face.

For a pure inductor, the current phasor sits a quarter-turn *behind* it — at $0^\circ$, pointing straight right.

Both arrows spin counter-clockwise together, at the same rate $\omega$, forever staying a quarter-turn apart. At any instant, the voltage is the vertical height of its arrow; the current is the vertical height of the other arrow.

Check: when the voltage arrow reaches straight up (its peak, height $=V_0$), the current arrow is still pointing straight right (height $=0$) — current has not peaked yet, exactly as the hook found by direct calculation. A quarter-turn later, the current arrow reaches straight up and peaks, while the voltage arrow has moved on to pointing straight left (height $=0$ again, now falling).

This spinning-arrow picture is the same back-emf idea from self-inductance: the coil never lets current change instantly, so current always arrives one quarter-turn late.
