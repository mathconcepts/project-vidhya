All four colligative properties depend on particle count, but they are not interchangeable in which CONCENTRATION unit their formula actually uses — mixing these up is a genuine, common error.

Relative lowering of vapour pressure uses **mole fraction**: $\dfrac{p^\circ-p_s}{p^\circ}=i\,x_{\text{solute}}$. Boiling-point elevation and freezing-point depression use **molality**: $\Delta T_b=iK_bm$, $\Delta T_f=iK_fm$. Osmotic pressure uses **molarity**: $\Pi=iCRT$.

Using molality where mole fraction belongs (or vice versa) gives a subtly wrong answer whenever the solution is not extremely dilute, since mole fraction and molality only track each other closely at very low concentration. **Knowing which colligative property is being asked for is necessary before choosing a formula — the concentration unit each one demands is not interchangeable with the others.**
