Chemistry's own first law, $\Delta U = q + w$, defines $w$ as work done **on** the system (compression is positive) — the IUPAC convention this syllabus uses.

The physics thermodynamics chapter met the same week usually writes $\Delta U = q - w$, with $w$ as work done **by** the system (expansion is positive) — the exact opposite sign for $w$.

Both describe the same physical reality; only the bookkeeping direction of $w$ differs. Carrying a physics-derived $w$-sign straight into a chemistry problem (or vice versa) flips the sign of every work term computed afterward, silently — the numbers still look reasonable, and the mistake is invisible unless the convention itself is checked first, every time a "work done" value crosses between the two subjects.
