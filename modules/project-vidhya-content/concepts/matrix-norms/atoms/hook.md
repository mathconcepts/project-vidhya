When you solve a linear system $Ax = b$ on a computer, tiny rounding errors can explode into wildly wrong answers — or barely matter. The difference between stable and unstable? **Matrix norms** and the **condition number** $\kappa(A)$, which measure how sensitive a solution is to perturbations.
