Take one loop: a $12\ \text{V}$ cell, no internal resistance for now, and a $4\ \Omega$ resistor. Pick a walking direction around the loop — say, the same direction the current flows.

Crossing the cell from $-$ to $+$: this is a rise, so add $+12$.

Crossing the resistor in the walking direction: this is a drop, so subtract $IR$, giving $-4I$.

Back to the start, total must be zero: $12-4I=0$, so $I=3\ \text{A}$.

Now walk the *other* way around the same loop instead. Every sign flips: crossing the cell $+$ to $-$ is now a drop ($-12$), and crossing the resistor against the current is a rise ($+4I$). The equation becomes $-12+4I=0$, giving the exact same $I=3\ \text{A}$. Either walking direction works, as long as every sign inside that one equation stays consistent with it.
