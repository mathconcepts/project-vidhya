From memory, before checking: what single question distinguishes when to use $P(n,r)$ versus $C(n,r)$?

<details>
<summary>Answer</summary>

Does the order of the selected items matter? Yes → permutation $P(n,r)$; no → combination $C(n,r) = P(n,r)/r!$.
</details>
