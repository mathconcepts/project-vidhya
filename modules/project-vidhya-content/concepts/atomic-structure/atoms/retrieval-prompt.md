**Question:** Name the four quantum numbers, what each one describes, and its allowed range of values. Then state Hund's rule in one line.

<details>
<summary>Answer</summary>

- $n$ (principal): which shell; values $1, 2, 3, \dots$
- $l$ (azimuthal): which subshell, sets orbital shape; values $0$ to $n-1$ ($s,p,d,f$)
- $m_l$ (magnetic): orbital orientation; values $-l$ to $+l$
- $m_s$ (spin): electron spin; $+\tfrac{1}{2}$ or $-\tfrac{1}{2}$

**Hund's rule:** orbitals of equal energy are filled singly, with parallel spin, before any one of them is doubly occupied.

</details>
