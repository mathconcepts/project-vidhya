From memory, before checking: what must always be true about the number of odd-degree vertices in a graph, and why?

<details>
<summary>Answer</summary>

Always even. Because $\sum\deg(v)=2|E|$ is even, and an odd count of odd-valued terms in that sum would make the total odd — a contradiction.
</details>
