Is $f(x)=|x-2|$ differentiable at $x=2$?

<details><summary>Answer</summary>No. Left-hand derivative: for $x<2$, $f(x)=2-x$, so $f'(x)=-1$. Right-hand derivative: for $x>2$, $f(x)=x-2$, so $f'(x)=1$. $-1\neq1$, so no single derivative exists at $x=2$ — the function is continuous there (no gap) but has a corner.</details>
