A rule: today's count is $5\times$ yesterday minus $6\times$ the day before.

Day $0$: $2$. Day $1$: $5$.

Day $2$: $5(5)-6(2)=25-12=13$.

Day $3$: $5(13)-6(5)=65-30=35$.

Each new value uses only the two before it.
