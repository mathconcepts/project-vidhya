**Arithmetic progression (AP):** add the same number each time. $2,5,8,11,\dots$ — add $3$ every step.

**Geometric progression (GP):** multiply by the same number each time. $2,6,18,54,\dots$ — multiply by $3$ every step.

**Harmonic progression (HP):** take the reciprocals of the terms. If those reciprocals form an AP, the original sequence is an HP.

**Three means, small worked check.** Take $a=4$, $b=16$. AM $=(4+16)/2=10$. GM $=\sqrt{4\times16}=\sqrt{64}=8$. HM $=\dfrac{2\times4\times16}{4+16}=\dfrac{128}{20}=6.4$. Check the order: $10 > 8 > 6.4$ — AM $\geq$ GM $\geq$ HM holds, with AM biggest and HM smallest.

**Telescoping, in one line.** If a term can be split into (piece) $-$ (next piece), a long sum of such terms collapses: only the very first piece and the very last piece survive; everything else cancels.
