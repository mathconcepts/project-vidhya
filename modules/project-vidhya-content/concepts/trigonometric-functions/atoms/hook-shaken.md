A Ferris wheel cabin's height is $R\sin\theta$. Set $\sin\theta=0.5$. A calculator gives one angle: $30°$. Check $\theta=150°$ too: $\sin150°=\sin(180°-30°)=\sin30°=0.5$. Same height, a second angle. The wheel does not stop after one turn. Add $360°$ to either angle and it still works. One number cannot list an endless set of angles. Trigonometric equations write that whole list as one formula instead: $\theta=n\pi+(-1)^n\alpha$, where $\alpha$ is the first angle you found and $n$ is any whole number.
