$xx_1+yy_1=a^2$ (or the general $T\equiv xx_1+yy_1+g(x+x_1)+f(y+y_1)+c=0$) is written down identically whether $(x_1,y_1)$ is outside, on, or inside the circle — the formula never checks. The picture it describes is only genuine two-real-tangent-lines-and-their-chord when the point is actually outside, where $S_1=x_1^2+y_1^2-a^2>0$.

Feed in a point strictly inside the circle instead, and $T=0$ still produces a perfectly good straight line — the polar of that point — but no real tangent touches the circle there at all, so calling it a "chord of contact" would describe a chord that doesn't connect any real touch points. A question that asks for the polar of an interior point is testing exactly this: same formula, no physical tangents behind it.
