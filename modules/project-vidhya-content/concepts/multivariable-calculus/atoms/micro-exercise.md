For $f(x, y) = x^3 + 2xy^2 - y^3$, find $\frac{\partial f}{\partial x}$.

- **(A)** $3x^2 + 2y^2$
- **(B)** $3x^2 + 4xy - 3y^2$
- **(C)** $4xy$
- **(D)** $2x + 4y$

<details>
<summary>Answer</summary>

**A**. Treat $y$ as a constant and differentiate with respect to $x$:

$$\frac{\partial f}{\partial x} = \frac{\partial}{\partial x}[x^3 + 2xy^2 - y^3] = 3x^2 + 2y^2 + 0 = 3x^2 + 2y^2$$

</details>
