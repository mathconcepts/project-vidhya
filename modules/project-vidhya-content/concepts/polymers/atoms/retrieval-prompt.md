**Question:** State the one test that decides whether a polymer forms by addition or condensation polymerisation. Then name the monomers of nylon-6,6 and state which category it falls into.

<details>
<summary>Answer</summary>

**The test:** does a small molecule (usually water) get released when the monomers join? No release means addition polymerisation; release at each bond means condensation polymerisation.

**Nylon-6,6:** made from hexamethylenediamine and adipic acid, joined by amide bonds that each release one water molecule — **condensation** polymerisation.

</details>
