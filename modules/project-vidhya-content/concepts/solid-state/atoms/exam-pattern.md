**How JEE actually asks this.**

- **NAT: density of a unit cell.** Given the structure type (which fixes $Z$), molar mass, and edge length, apply $\rho=ZM/(N_Aa^3)$ directly — converting the edge length to centimetres is the one step most likely to go wrong under time pressure.

- **MCQ: matching a structure to its $Z$, coordination number, and packing efficiency together.** These three numbers travel as a set (simple cubic: $1$, $6$, $52.4\%$; bcc: $2$, $8$, $68\%$; fcc: $4$, $12$, $74\%$) — a distractor usually mismatches one number from a different structure's set.

- **Trap: reversing which point defect lowers density.** A Schottky defect lowers density (ions actually leave the crystal); a Frenkel defect does not (the ion just moves within the crystal).

- **Time budget:** a direct density NAT, with the structure type already stated, should take under $60$ seconds once the unit conversion is done correctly.

- **A note on this unit's current status:** this topic — crystal lattices, unit cells, and packing efficiency — is genuine Class 12 board content and has been asked in JEE Main in past years, but it is widely reported to have been dropped in a recent NTA syllabus rationalisation.
