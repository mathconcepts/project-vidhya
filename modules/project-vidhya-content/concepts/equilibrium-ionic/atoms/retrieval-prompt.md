**Question:** State the Henderson–Hasselbalch equation for an acidic buffer, and state what the pH equals when $[\text{A}^-]=[\text{HA}]$.

<details>
<summary>Answer</summary>

$\text{pH} = \text{p}K_a + \log_{10}\!\left(\dfrac{[\text{A}^-]}{[\text{HA}]}\right)$.

When $[\text{A}^-]=[\text{HA}]$, the ratio is $1$, $\log_{10}(1)=0$, so $\text{pH} = \text{p}K_a$ exactly.

</details>
