Four stories, four distributions.

Fixed number of trials, same success chance each time, count the successes — that's **Binomial**.

Rare events over a time window, no fixed trial count — that's **Poisson**.

Keep going until the *first* success — that's **Geometric**.

Draw from a fixed pool *without* replacement, where each draw changes the odds — that's **Hypergeometric**.

Match the story's shape to one of these four before writing any formula.
