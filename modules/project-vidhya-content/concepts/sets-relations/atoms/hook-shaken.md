Sort $1,2,3,4,5,6$ into piles: same pile if they leave the same remainder on division by $3$.

$1$ and $4$: both remainder $1$. Same pile.
$2$ and $5$: both remainder $2$. Same pile.
$3$ and $6$: both remainder $0$. Same pile.

Three piles, no number left over, none in two piles at once. That clean split happens because the sorting rule is reflexive, symmetric, and transitive — all three, together.
