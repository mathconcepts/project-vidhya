**Question (1 mark).** Define linear independence. A set of vectors $\{v_1, v_2, \ldots, v_k\}$ is linearly independent if ______.

<details>
<summary>Answer</summary>

**Answer:** A set of vectors $\{v_1, v_2, \ldots, v_k\}$ is linearly independent if the only solution to $c_1 v_1 + c_2 v_2 + \cdots + c_k v_k = \mathbf{0}$ is $c_1 = c_2 = \cdots = c_k = 0$ (the trivial solution).

**Alternative phrasing (also correct):** ...if no vector in the set can be expressed as a linear combination of the others.

</details>
