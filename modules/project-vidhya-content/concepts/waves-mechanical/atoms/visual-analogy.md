A Mexican wave in a cricket stadium looks exactly like a mechanical wave in slow motion: each spectator only ever stands up and sits back down, in their own seat, never moving sideways at all — yet the "wave" itself sweeps all the way around the stadium, seat by seat, far faster than any single person could run that distance. What travels around the ground is the *pattern* of standing up, not the spectators themselves.

The curve on this card is a snapshot of a wave frozen at each instant, redrawn slightly shifted for the next instant — the same repeating hump-and-trough shape sliding steadily to the right, exactly like the standing-up pattern sliding around the stadium. Watch any single point on the curve (any one "seat"): it only ever moves up and down as the shape slides past it, never sideways with the wave.
