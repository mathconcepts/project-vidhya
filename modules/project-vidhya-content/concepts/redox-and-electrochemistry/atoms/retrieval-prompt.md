**Question:** State the Nernst equation at $298\ \text{K}$, and state which electrode (anode or cathode) is positive in a galvanic cell versus an electrolytic cell.

<details>
<summary>Answer</summary>

$E_{\text{cell}} = E^\circ_{\text{cell}} - \dfrac{0.0591}{n}\log_{10}Q$ at $298\ \text{K}$.

**Galvanic cell:** anode is negative, cathode is positive.
**Electrolytic cell:** anode is positive, cathode is negative.

In both cell types, the anode is always where oxidation happens and the cathode is always where reduction happens — only the sign of each terminal changes.

</details>
