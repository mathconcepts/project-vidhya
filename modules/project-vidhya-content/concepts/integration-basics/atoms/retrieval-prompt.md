Evaluate $\int (\sin(x) + 2\cos(x)) \, dx$.

- **(A)** $\cos(x) + 2\sin(x) + C$
- **(B)** $-\cos(x) + 2\sin(x) + C$
- **(C)** $\sin(x) + 2\cos(x) + C$
- **(D)** $-\sin(x) - 2\cos(x) + C$

<details>
<summary>Answer</summary>

**B**. $$\int \sin(x) \, dx = -\cos(x)$$
$$\int 2\cos(x) \, dx = 2\sin(x)$$

Total: $-\cos(x) + 2\sin(x) + C$

</details>
