Which order of increasing first ionisation enthalpy is correct for nitrogen, oxygen, fluorine and neon?

A) $N < O < F < Ne$
B) $O < N < F < Ne$
C) $O < N < Ne < F$
D) $N < O < Ne < F$
E) $F < Ne < N < O$

<details>
<summary>Answer</summary>

**Correct answer: B) $O < N < F < Ne$.**

The real values, in kJ/mol, are N = 1402, O = 1314, F = 1681, Ne = 2081. Sorting these gives $1314 < 1402 < 1681 < 2081$, i.e. $O < N < F < Ne$.

**Why the others fail:**
- A) puts them in plain left-to-right order, missing that nitrogen's half-filled $2p^3$ makes it harder to ionise than oxygen's paired $2p^4$ — the one flip in this group of four.
- C) and D) swap Ne and F, but $F \to Ne$ is an ordinary step (no filled-or-half-filled subshell is being broken), so the plain rising trend applies there.
- E) reverses the whole order, as if ionisation enthalpy fell across the period instead of rising.

</details>
