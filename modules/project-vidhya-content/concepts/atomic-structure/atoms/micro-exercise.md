Which of the following $(n, l)$ pairs is **not** a valid combination of quantum numbers?

A) $(2, 1)$
B) $(3, 2)$
C) $(3, 3)$
D) $(4, 0)$
E) $(1, 0)$

<details>
<summary>Answer</summary>

**Correct answer: C) $(3, 3)$.**

The rule is $l$ can range from $0$ to $n-1$. For $n=3$, the maximum allowed value of $l$ is $3-1=2$. So $l=3$ is not allowed when $n=3$ — this pair is invalid.

**Why the others pass:**
- A) $n=2$ allows $l=0$ or $1$; $l=1$ is fine.
- B) $n=3$ allows $l=0,1,2$; $l=2$ is fine.
- D) $n=4$ allows $l=0,1,2,3$; $l=0$ is fine.
- E) $n=1$ allows only $l=0$; that is exactly what is given.

</details>
