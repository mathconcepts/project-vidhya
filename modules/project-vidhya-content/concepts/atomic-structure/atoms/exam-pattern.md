**How JEE actually asks this.**

- **NAT: energy or wavelength of a specific hydrogen transition.** Given two values of $n$, apply $\Delta E = 13.6\left(\dfrac{1}{n_1^2}-\dfrac{1}{n_2^2}\right)$ eV directly with $n_1$ the lower level — no need to compute $E_1$ and $E_2$ separately first.

- **MCQ: electron configuration or valid quantum-number set for a given element or ion.** Write the configuration using Aufbau's actual energy order (not shell-number order), then apply Hund's rule to the last, partially filled subshell before answering how many electrons are unpaired.

- **Trap: quantum-number validity checked one number at a time.** A distractor set like $(n,l)=(2,2)$ passes a lazy "is $n$ valid? is $l$ valid?" check on each number separately — only checking $l \le n-1$ together catches it.

- **Trap: ion configurations remove electrons from the outermost shell, not the last-filled subshell.** For a transition-metal ion, electrons are lost from the highest $n$ orbital first (usually $s$), even if a $d$ orbital was filled after it — this reverses the filling order.

- **Time budget:** a direct energy/wavelength NAT should take under 40 seconds using the combined $\Delta E$ formula. A configuration-and-unpaired-electrons MCQ needs closer to 60–75 seconds to fill and check Hund's rule properly.
