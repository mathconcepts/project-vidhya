Take $A = \{1,2,3\}$ and $B = \{4,5,6,7\}$. Draw an arrow from $1 \to 4$, from $2 \to 5$, from $3 \to 4$. Every element of $A$ has exactly one arrow out — that is a **function**.

The **domain** is $A = \{1,2,3\}$ — all three elements are used. The **codomain** is all of $B = \{4,5,6,7\}$. The **range** is only the elements actually hit: $\{4, 5\}$ — note $6$ and $7$ got no arrow. Range $\{4,5\} \ne$ codomain $\{4,5,6,7\}$, so this function is **not onto**.

Is it **one-one**? Elements $1$ and $3$ both sent their arrow to $4$ — two different inputs, same output. So this function is not one-one either.

A **set** is any well-defined collection — you can always check if something belongs. A **relation** is any set of arrows at all, with no rule; a function adds the rule: exactly one arrow out of every input.
