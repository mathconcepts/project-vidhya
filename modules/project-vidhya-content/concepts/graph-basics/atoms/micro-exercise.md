A simple graph has 5 vertices, each of degree 4. How many edges does it have?

<details>
<summary>Answer</summary>

$\sum\deg(v)=5\times4=20$, so $|E|=20/2=10$. (This is $K_5$ — degree 4 is the maximum possible on 5 vertices, so every pair must already be joined.)
</details>
