Let $A = \begin{pmatrix} 3 & 0 \\ 0 & 2 \end{pmatrix}$. Without computing the full SVD, find $\|A\|_2$ and $\|A\|_F$.

<details><summary>Answer</summary>

For a diagonal matrix, singular values equal the absolute values of the diagonal entries: $\sigma_1=3$, $\sigma_2=2$. $\|A\|_2=\sigma_1=3$. $\|A\|_F=\sqrt{\sigma_1^2+\sigma_2^2}=\sqrt{9+4}=\sqrt{13}$.
</details>
