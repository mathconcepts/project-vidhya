The order and degree of $\dfrac{d^2y}{dx^2}=\sqrt{1+\left(\dfrac{dy}{dx}\right)^2}$ are:

(A) Order $2$, degree $2$
(B) Order $2$, degree $1$
(C) Order $1$, degree $2$
(D) Order $2$, degree undefined
(E) None of these

<details>
<summary>Answer</summary>

**Correct answer: (A) — order $2$, degree $2$**

The highest derivative present is $\dfrac{d^2y}{dx^2}$, so the order is $2$. The equation has a square root on the right side, so degree cannot be read off yet — clear the radical first by squaring both sides:

$$\left(\frac{d^2y}{dx^2}\right)^2 = 1+\left(\frac{dy}{dx}\right)^2$$

Now the equation is a polynomial in its derivatives. The highest-order derivative, $\dfrac{d^2y}{dx^2}$, appears to the power $2$ — so the degree is $2$.

**Why the others are wrong:** (B) correctly identifies the order but reads the degree before squaring, when the radical is still present — degree is not yet defined at that stage. (C) has the order and degree swapped. (D) is wrong because the degree IS well-defined once the radical is cleared; it only looks undefined before that step.

</details>
