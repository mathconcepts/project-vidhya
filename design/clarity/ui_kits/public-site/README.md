# UI kit — marketing site & blog

Built from `frontend/src/pages/app/MarketingLanding.tsx` and the Blog section of
the repo's `DESIGN-SYSTEM.md`. Touchpoints in `guidelines/journey-public-channels.md`.

- **The sample problem is the hero's equal**, not an afterthought — answer it in
  place and the verdict changes. The first problem beats the first page of copy.
- **All three gradients are gone** (hero wash, gradient headline text, gradient
  CTA). One green CTA, repeated once, pointing at the same diagnostic.
- **Architecture language stays collapsed** — students never meet "3072-dim
  embeddings" unless they open the builders' section.
- **Blog is the same system**, not a themed cousin: same greys, same type, 19px
  prose at a 68-character measure. The receipt marker crosses over — a verified
  derivation is bordered, the argument around it is not.
- **One sticky bridge bar**, on material, offering practice (green) or the tutor
  (indigo).
