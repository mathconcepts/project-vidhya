**Huckel's rule** says a ring is aromatic (unusually stable) only if it is cyclic, **planar** (flat — every ring atom lying in one plane), fully **conjugated** (every ring atom carries a p-orbital, so the pi electrons can spread all the way around with no gap), and holds exactly $4n+2$ pi electrons for some whole number $n=0,1,2,\dots$. Miss any one of the first three conditions and the electron count stops mattering.

**Benzene**, $\text{C}_6\text{H}_6$: six carbons, each with one p-orbital, each contributing one electron to the ring — $6$ pi electrons. Set $4n+2=6$: $n=1$, a whole number. Aromatic, and the extra stability is exactly why it resists addition reactions that would break up that ring of $6$.

**Naphthalene**, the two fused six-membered rings in mothballs: $10$ pi electrons shared across the whole fused system. Set $4n+2=10$: $n=2$, again a whole number. Aromatic.

**Cyclobutadiene**, $\text{C}_4\text{H}_4$: four carbons, four pi electrons. Set $4n+2=4$: solving gives $n=0.5$, not a whole number — this ring is **not** aromatic. Worse, $4$ pi electrons is exactly a $4n$ count ($n=1$), which makes it **antiaromatic**: less stable than an open-chain molecule with the same bonds would be, not more.
