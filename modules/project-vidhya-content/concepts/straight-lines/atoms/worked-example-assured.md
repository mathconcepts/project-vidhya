**Bisectors of $L_1: 3x+4y-6=0$ and $L_2: 4x+3y-4=0$.** $c_1,c_2$ already same sign; $\sqrt{a_1^2+b_1^2}=\sqrt{a_2^2+b_2^2}=5$. Setting $\dfrac{3x+4y-6}{5}=\pm\dfrac{4x+3y-4}{5}$ gives $x-y+2=0$ ($+$) and $7x+7y-10=0$ ($-$). Since $a_1a_2+b_1b_2=24>0$ with $c_1,c_2$ same sign, the $-$ result is acute: $7x+7y-10=0$.

**Where this actually costs marks: the $\pm$ ambiguity is not decoration.** A student who writes down one bisector equation and calls it "the" bisector — without running the $a_1a_2+b_1b_2$ test — has a 50% chance of naming the obtuse one instead, and both equations look equally plausible sitting side by side. The two bisectors are always perpendicular to each other (their slopes here, $-1$ and $1$, multiply to $-1$) — a useful sanity check, but it does not tell you WHICH one is acute, only that they are a legitimate pair.

Note also that this specific example is symmetric only by coincidence: both normalisers came out to $5$ because $\{3,4\}$ and $\{4,3\}$ are the same pair of numbers reordered. When $a_1^2+b_1^2\neq a_2^2+b_2^2$, both denominators must still be carried through explicitly — dropping either one silently changes which bisector each sign produces.
