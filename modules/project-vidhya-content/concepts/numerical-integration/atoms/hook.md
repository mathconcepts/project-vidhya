You need the area under a curve, but the function is too ugly to integrate by hand — or you only have it as a table of measured values, no formula at all. Numerical integration approximates that area by slicing it into strips and summing them. The trapezoidal rule uses slanted-roof strips, cheap but rough; Simpson's rule uses curved-roof strips, costing the same number of evaluations but landing far closer to the true area.
