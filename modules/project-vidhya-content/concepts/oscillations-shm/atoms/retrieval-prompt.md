**Question:** Write the displacement, velocity, and acceleration equations for SHM. Then state the time period formulas for a spring-mass system and a simple pendulum.

<details>
<summary>Answer</summary>

$x(t)=A\sin(\omega t+\phi)$, $v(t)=A\omega\cos(\omega t+\phi)$, $a(t)=-\omega^2x(t)$.

**Spring-mass:** $T=2\pi\sqrt{m/k}$.
**Simple pendulum** (small angle): $T=2\pi\sqrt{L/g}$.

</details>
