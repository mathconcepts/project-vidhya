A field assigns one vector per **point**, not per particle. The curve a released particle would trace — the flow line — is a derived object, produced only by integrating the field along a path; it is not what the field hands you at a single location. Treating "the arrow at $(x,y)$" and "the trajectory through $(x,y)$" as the same thing is where a GATE flow-line question quietly loses marks.

Every field is a function $\mathbf F:\mathbb R^n\to\mathbb R^n$. Only some fields are **gradients** of a scalar — that is the narrower, stronger claim tested later in this topic, not a property every field has for free.
