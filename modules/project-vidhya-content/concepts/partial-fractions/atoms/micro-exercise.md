Decompose $\frac{7}{(x-1)(x+2)}$ into partial fractions.

- **(A)** $\frac{7/3}{x-1} + \frac{7/3}{x+2}$
- **(B)** $\frac{7/3}{x-1} - \frac{7/3}{x+2}$
- **(C)** $\frac{1}{x-1} + \frac{1}{x+2}$
- **(D)** $-\frac{7/3}{x-1} + \frac{7/3}{x+2}$

<details>
<summary>Answer</summary>

**B**. Set up: $\frac{7}{(x-1)(x+2)} = \frac{A}{x-1} + \frac{B}{x+2}$

Multiply by $(x-1)(x+2)$: $7 = A(x+2) + B(x-1)$

At $x = 1$: $7 = A(3) \Rightarrow A = 7/3$
At $x = -2$: $7 = B(-3) \Rightarrow B = -7/3$

Answer: $\frac{7/3}{x-1} - \frac{7/3}{x+2}$

</details>
