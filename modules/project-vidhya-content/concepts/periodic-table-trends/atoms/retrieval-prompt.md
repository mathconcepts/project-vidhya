**Question:** State how first ionisation enthalpy changes across a period and down a group, then name the two configuration-based exceptions found in every period.

<details>
<summary>Answer</summary>

**Across a period:** rises (effective nuclear charge increases, same shell).
**Down a group:** falls (a new, farther shell dominates over extra protons).

**Exception 1:** filled subshell to next subshell — e.g. $2s^2$ (Be) to $2s^22p^1$ (B). The filled subshell is extra stable, so the element right after it has a *lower* ionisation enthalpy than expected.

**Exception 2:** half-filled subshell to paired subshell — e.g. $2p^3$ (N) to $2p^4$ (O). The half-filled subshell is extra stable (no electron-pair repulsion), so the element right after it has a *lower* ionisation enthalpy than expected.

</details>
