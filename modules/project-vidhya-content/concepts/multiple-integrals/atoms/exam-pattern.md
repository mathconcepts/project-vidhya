**How GATE actually asks this.**

- **NAT questions** typically ask for the numeric value of a double integral over a rectangle or a simple Type I/Type II region.
- **MCQ questions** commonly test the correctly REVERSED order of integration — pick the option with bounds that actually describe the same region, not just swapped differentials.
- **MSQ questions** may ask which coordinate description (Cartesian vs polar) correctly represents a given region — more than one can be correct at once.

**Worked numeric pattern.** Area of the triangle under $y=x$, $0\le x\le1$: $\int_0^1\int_0^x 1\,dy\,dx=\int_0^1 x\,dx=\tfrac12$.

**Time budget.** About $3$–$4$ minutes for a straightforward double integral; longer if an order-swap or a coordinate change is required first.
