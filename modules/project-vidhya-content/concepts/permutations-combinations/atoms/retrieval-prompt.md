**Question:** State the fundamental counting principle in one sentence. Then state the formula for arranging $n$ items where $p$ of them are identical of one kind and $q$ identical of another kind.

<details>
<summary>Answer</summary>

**Fundamental counting principle:** if a first task can be done in $m$ ways and a second, independent task in $n$ ways, both together can be done in $m \times n$ ways.

**Arrangements with repeats:** $\dfrac{n!}{p!\,q!}$.

</details>
