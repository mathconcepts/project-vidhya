Bohr's model correctly predicts hydrogen's spectral lines from $E_n = -\dfrac{13.6}{n^2}$ eV — but it is a model for **hydrogen alone** (one electron, one proton), and treating an electron as orbiting on a fixed circular path at all is already known to be wrong.

The real picture, from quantum mechanics: an electron does not travel a path — it exists in an **orbital**, a three-dimensional region where it is *probably* found, described by a wavefunction, not a trajectory. Bohr's neat circular orbit is a useful bridge picture for getting the energy formula right, not a literal description of where the electron is at any instant.

The energy-level formula survives (and generalises, via quantum numbers, to multi-electron atoms' subshells); the orbit picture itself does not.
