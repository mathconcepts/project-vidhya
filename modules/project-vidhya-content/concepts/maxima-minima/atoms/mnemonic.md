**Cup holds water, cap sheds it.** A positive second derivative curves the graph like a **cup** — it can hold a puddle, so it sits at a **minimum**. A negative second derivative curves it like a **cap** — water runs off, so it sits at a **maximum**. $f''(c) > 0 \Rightarrow$ cup $\Rightarrow$ min; $f''(c) < 0 \Rightarrow$ cap $\Rightarrow$ max.

**Worked micro-example:** $f(x) = x^2 - 6x + 5$. $f'(x) = 2x-6=0$ gives $x=3$. $f''(x)=2>0$ — a cup, so $x=3$ is a local minimum, with $f(3) = 9-18+5=-4$.

**Sanity-check reflex:** evaluate $f$ at one point on each side of the critical value and compare to $f(c)$. Here, $f(2)=-3$ and $f(4)=-3$, both above $f(3)=-4$ — exactly the dip a minimum should produce.
