At height $h=R$ above Earth's surface (where $R$ is Earth's radius), the acceleration due to gravity is $g'=g/n$ for some number $n$. What is $n$? (Surface value is $g$.)

A) $n=2$
B) $n=3$
C) $n=4$
D) $n=1$ (unchanged)
E) $n=1/4$ (gravity gets stronger)

<details>
<summary>Answer</summary>

**Correct answer: C) $n=4$.**

$g' = g\left(\dfrac{R}{R+h}\right)^2$. With $h=R$: $g' = g\left(\dfrac{R}{2R}\right)^2 = g\left(\dfrac12\right)^2 = \dfrac{g}{4}$. So $n=4$.

**Why the others fail:**
- A) $n=2$ comes from using $g'=g(R/(R+h))$ without squaring — forgetting gravity is an inverse-*square* law.
- B) $n=3$ has no clean derivation from either the height or depth formula; it's a plausible-looking guess with no formula behind it.
- D) assumes gravity never changes with height at all — true only as a rough approximation for very small $h$, not for $h=R$.
- E) reverses the direction entirely — gravity always weakens (never strengthens) as you move farther from the centre.

</details>
