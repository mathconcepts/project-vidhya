"Tertiary substrate, so the reagent decides nothing" is a genuine trap — the *substrate class* only narrows which mechanisms are even possible; the reagent still decides which one actually happens.

Counterexample: 2-bromo-2-methylpropane, $(\text{CH}_3)_3\text{CBr}$, reacts with plain hot water by ionising on its own (a stable tertiary carbocation forms first). The same molecule treated with a strong, bulky base instead — sodium ethoxide, say — barely substitutes at all; it eliminates, pulling off a neighbouring hydrogen to form an alkene.

Same tertiary carbon, same halogen, opposite outcome — because the reagent, not just the substrate, is half the decision.
