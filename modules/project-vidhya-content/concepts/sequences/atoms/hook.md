A sequence hands you one number at a time and asks a single question: does the run ever settle down? Take $a_n = \dfrac{2n+1}{n}$ — term 1 is $3$, term 2 is $2.5$, term 3 is $2.33$. Before computing term 100, guess where this is headed. The terms themselves never equal that number; they only crowd arbitrarily close to it, forever. That gap between "gets close to" and "equals" is the whole idea a limit is built to capture — and not every sequence keeps this promise. Some settle. Some swing between two values forever. Some run off unbounded. Telling which one you're looking at, before grinding out ten terms by hand, is the skill this topic builds first.
