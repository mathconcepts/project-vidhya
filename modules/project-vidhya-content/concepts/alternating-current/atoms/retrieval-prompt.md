**Question:** Write the formula for the impedance of a series LCR circuit, the condition for resonance, and the resonant angular frequency $\omega_0$.

<details>
<summary>Answer</summary>

**Impedance:** $Z = \sqrt{R^2 + (X_L-X_C)^2}$, where $X_L=\omega L$ and $X_C = 1/(\omega C)$.

**Resonance condition:** $X_L = X_C$, so $Z = R$ (its minimum value) and current is maximum.

**Resonant angular frequency:** $\omega_0 = \dfrac{1}{\sqrt{LC}}$.

</details>
